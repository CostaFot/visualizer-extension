Visualizer for Command Palette

A live audio spectrum visualizer — pinned right inside Windows PowerToys Command Palette.

Visualizer is an open-source PowerToys Command Palette extension that turns whatever your machine is playing into a tiny live spectrum display: pinnable Dock buttons in three styles (block bars, braille, and a VU-colored dot) plus a full in-palette canvas with vertical bars and an oscilloscope. It listens to your default output device via Windows loopback capture — no microphone, no recording, no network, no accounts — and everything happens in memory on your machine.
